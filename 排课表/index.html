导入 / 导出

导出包含：班级 / 教师 / 科目 / 连排配置 / 时间设置 / 节假日调休 / 全部班级课表（含单双周、代课）/ 课时记录 / 历史版本 / 调课记录。导入遇同名班级、同名或同 ID 教师、同名科目时，将弹窗询问「覆盖 / 合并 / 跳过」。

课表容量

范围：天数 5–7，节数 6–12。修改后已有课表将按新尺寸裁剪/补空。

每节上下课时间

例如：第1节 8:00-8:45。填写后课表视图会显示节次时间。

节假日 / 调休标记

标记节假日（该日不排课）；调休日（如周六上周三的课）。仅用于备忘与导出，不影响网格排课。

教师不排课时间

勾选网格标记该教师在该节不可排课（如周三第3节有会议）。

班级固定无课时间

勾选网格标记该班级该节固定无课（如周五下午班会）。

排课

点击课格可修改科目/教师/周次/代课/锁定；自动排课默认全周，手动调整时可设置单周/双周。每次自动排课自动保存历史版本。
